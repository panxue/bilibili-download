# Iteration 1.0.0 — Initial public release

First public release. The private development history (0.1.0 docs baseline → 0.2.0–0.5.3) is consolidated into a single clean commit before making the repo public.

## Changes

| Topic | Before → After | Reason |
|-------|----------------|--------|
| Version | pyproject `0.1.0` / userscript `0.1.0` / `/api/health` `0.1.0` → all `1.0.0` | a public release starts at the stable 1.0.0 baseline, giving downstream consumers a real version to pin |
| Changelog index | historical pre-release entries 0.2.0–0.5.3 + a docs-phase `1.0.0` baseline → new `1.0.0` public-release entry at top; old baseline renamed to `0.1.0` | two entries under the same version `1.0.0` would be ambiguous; renaming the docs-only baseline to `0.1.0` keeps versions unique and sorted |
| Language | code comments / docs / userscript UI in Chinese → all English | international audience once the repo is public; the previous change already converted content, this release pins it as the public baseline |
| License | none → MIT (`LICENSE`) | a public repo without a license reserves all copyright by default, which blocks reuse; MIT chosen for a permissive utility tool |
| Git history | 14 commits with mixed Chinese/English messages → single squashed commit | public history must be clean; squashing also removes any stale pre-release noise before external contributors arrive |
| Docs | historical iteration records renamed/kept, new `docs/iterations/1.0.0.md` added | changelog index must point to a detail doc for every version (doc-standards) |

## Implementation notes

- Version bumps: `pyproject.toml` `[project].version`, userscript `@version`, `backend/main.py` `/api/health` `version` field.
- Changelog: newest-first ordering restored (`1.0.0` on top, `0.1.0` baseline at the bottom).
- `docs/iterations/1.0.0.md` renamed to `docs/iterations/0.1.0.md` (git mv) with the title and changelog link updated.
- `.gitignore` gained `.pytest_cache/` / `.ruff_cache/` so the squash commit does not pick up local caches.
- Runtime artifacts (`data/cookies.txt`, `data/jobs.db`, `downloads/`) stay gitignored and never enter the public repo.
