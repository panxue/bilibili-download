# Iteration 0.5.0 — Docker Compose support

## Changes

- Containerization | none → `Dockerfile` (multi-stage uv dependency layer + python:3.14-slim runtime) | another way to run the backend locally, equivalent to `start.sh`; ffmpeg + yt-dlp==2026.07.04(pip) guaranteed available in PATH
- Build broken-symlink fix | `uv:latest` as builder → `python:3.14-slim` as builder + copy the uv binary | the uv image downloads a separate Python for the 3.14 project, the `.venv/bin/python` symlink breaks after COPY; same-base-image approach guarantees the link points to /usr/local/bin/python3.14
- ffmpeg installation | apt install (133MB, direct deb.debian.org timeout/slow) → pip package `imageio-ffmpeg==0.6.0` + symlink into PATH | bundles static ffmpeg 7.0.2, avoids apt network issues; usable by both `shutil.which("ffmpeg")` and yt-dlp merge
- Package mirror | default PyPI → Tsinghua mirror `pypi.tuna.tsinghua.edu.cn` (uv `UV_DEFAULT_INDEX` + pip `-i`) | mainland direct connections to pypi.org/deb.debian.org time out; mirror installs in seconds in testing
- Compose | none → `compose.yaml` | port mapped loopback only `127.0.0.1:8000:8000`, volumes persist `downloads/` and `data/`, `.env` optionally passes through `BLDLP_*`
- Build context | none → `.dockerignore` | excludes .venv/downloads/data/config.toml/.env/.git
- Secrets | none → `.env` (gitignore) + `.env.example` | token never enters the image or git, only injected via env_file
- Dependency consistency | decision: **uv.lock stays gitignored** | only two version-range dependencies (fastapi/uvicorn), builder `uv sync --no-install-project --no-dev` resolves in real time and matches local, no drift risk, so not included in the build
- Runtime user | decision: **root** | local single-user tool, no volume permission-coordination burden
- Registry | decision: **no registry dependency** | compose `build: .` builds in place, artifacts only live on the local machine

## Implementation notes

- Documentation: design.md §6 promoted from "reserved" to "current", added compose/volume/port/security notes; config.md §3 added container env notes.
- End-to-end verification passed: `docker compose build` (image 381MB) → `up -d` → `/api/health` returns `ffmpeg:true, yt_dlp:2026.07.04` → guest `/api/info` network resolution returns 1080P list → real 480P multi-P download → `done` written to the volume `/app/downloads/{UPer}/...mp4` (visible on the host); job deletion and two-way volume I/O all normal.
- Environment dependencies: docker + compose plugin; the daemon needs HTTP_PROXY configured (local 127.0.0.1:7897) to pull the base image, inside the container the Tsinghua source is used.
